# EventHub - React Event Management System

## Features
- Separate Login and Sign Up pages
- Event listing and category filter
- Event details page
- Protected booking page
- My Bookings page
- LocalStorage demo authentication and bookings
- React Router navigation

## Run
```bash
npm install
npm run dev
```
Open the localhost URL shown by Vite.
